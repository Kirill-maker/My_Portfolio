# Portfolio Website - Lukin Kirill

Современный портфолио сайт с анимациями, пиксельным персонажем и кастомным курсором.

## 📁 Структура проекта

```
portfolio-website/
├── index.html          # Главная HTML страница
├── css/
│   └── style.css      # Все стили сайта
├── js/
│   ├── theme.js       # 🌓 Переключатель темы
│   ├── language.js    # 🌍 Переключатель языка
│   ├── cursor.js      # 🖱️ Супер плавный курсор
│   ├── pixel-art.js   # 🎨 Рендерер реалистичного персонажа
│   ├── character.js   # 👾 Анимация персонажа на главной
│   ├── game.js        # 🎮 Игра "Trash Runner"
│   ├── stats.js       # 📊 Анимация статистики
│   ├── filters.js     # 🎯 Фильтры проектов
│   └── main.js        # ⚙️ Основные функции
├── images/            # Папка для изображений (пока пустая)
└── README.md          # Этот файл
```

## 🚀 Как запустить

### Способ 1: Двойной клик
Просто дважды кликните на файл `index.html` - сайт откроется в браузере!

### Способ 2: Drag & Drop
Перетащите файл `index.html` в окно браузера (Chrome, Edge, Firefox).

### Способ 3: Live Server (для разработчиков)
Если установлен VS Code с расширением Live Server:
1. Откройте папку `portfolio-website` в VS Code
2. Правый клик на `index.html` → Open with Live Server

## ✨ Особенности

- 🎨 **Детальный пиксельный персонаж** - 96x144px, с улучшенными руками, ногами и анимацией
- 🎮 **Встроенная игра "Trash Runner"** - игра-раннер как Chrome Dino, кликни на персонажа!
- 🖱️ **Кастомный курсор-стрелка** - следует за мышкой с эффектами
- 💫 **Плавающие частицы** на фоне
- 📊 **Анимированная статистика** - числа считаются при прокрутке
- 🎯 **Фильтры проектов** - по категориям (UX/UI, WEB, MOTION)
- ⚡ **Технологии** - карточки с hover эффектами
- 🔄 **Бесконечный marquee** с навыками
- 🌓 **Переключатель темы** - светлая/темная тема (сохраняется в localStorage)
- 🌍 **Двуязычность** - английский/русский язык (сохраняется в localStorage)
- 📱 **Полностью адаптивный** дизайн для телефонов и планшетов

## 📝 Кастомизация

### Изменить цвета
Откройте `css/style.css` и измените переменные в `:root`:
```css
:root {
    --bg-color: #0a0a0a;
    --text-color: #ffffff;
    --text-secondary: #888888;
    --border-color: #2a2a2a;
}
```

### Изменить имя
Откройте `index.html` и найдите секцию `.hero-name`

### Добавить проекты
Откройте `index.html` и добавьте новый `.work-item` в секцию `.work-grid`

### Добавить технологии
Откройте `index.html` и добавьте новый `.tech-item` в секцию `.tech-grid`
