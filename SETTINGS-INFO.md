# 📝 Информация о настройках сайта

## 🔄 Автоматическое сохранение настроек

Ваш сайт **автоматически запоминает** выбор пользователя:

### 🌓 Тема (Светлая/Темная)
- **Где хранится:** `localStorage.getItem('theme')`
- **Значения:** `'light'` или `'dark'`
- **Сохраняется:** При каждом клике на кнопку 🌙/☀️
- **Загружается:** Мгновенно при открытии страницы (ДО отрисовки)

### 🌍 Язык (Русский/Английский)
- **Где хранится:** `localStorage.getItem('language')`
- **Значения:** `'ru'` или `'en'`
- **Сохраняется:** При каждом клике на кнопку RU/EN
- **Загружается:** При загрузке DOM

## 🔍 Как это работает?

### 1. Первое посещение:
```
Пользователь открывает сайт → Темная тема + Английский язык (по умолчанию)
```

### 2. Пользователь меняет настройки:
```
Клик на 🌙 → Меняется на ☀️ → Сохраняется 'light' в localStorage
Клик на RU → Меняется на EN → Сохраняется 'ru' в localStorage
```

### 3. Следующее посещение:
```
Пользователь открывает сайт → Читается localStorage → Применяются его настройки!
```

## 🛠️ Технические детали

### Тема загружается в 2 этапа:
1. **В `<head>`** - инлайн скрипт применяет класс `light-theme` к `<html>` (мгновенно)
2. **В `theme.js`** - синхронизирует с `<body>` и устанавливает иконку

Это **предотвращает мигание** темной темы при загрузке.

### Язык загружается в 1 этап:
1. **В `language.js`** - после загрузки DOM обходит все элементы с `data-en` и `data-ru`

## 🧪 Проверка работы

Откройте консоль браузера (F12) и увидите:
```
✅ Светлая тема загружена из памяти
✅ Язык "Русский" загружен из памяти
```

При изменении настроек:
```
💾 Темная тема сохранена
💾 Язык "Английский" сохранен
```

## 🗑️ Очистка настроек

Если нужно сбросить настройки (для тестирования):

### Вариант 1: Через консоль браузера
```javascript
localStorage.removeItem('theme');
localStorage.removeItem('language');
location.reload();
```

### Вариант 2: Очистить все данные
```javascript
localStorage.clear();
location.reload();
```

## 📱 Совместимость

Работает во всех современных браузерах:
- ✅ Chrome/Edge (Chromium)
- ✅ Firefox
- ✅ Safari
- ✅ Opera
- ✅ Mobile browsers (iOS Safari, Chrome Mobile)

**localStorage** поддерживается всеми браузерами с 2012 года!

## 🔒 Приватность

- Данные хранятся **локально** в браузере пользователя
- **НЕ отправляются** на сервер
- **НЕ используются** cookies
- Доступны **только** для вашего домена

---

**Итог:** Настройки сохраняются автоматически и навсегда (пока пользователь не очистит данные браузера)! 🎉
