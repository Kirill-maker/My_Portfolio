# 🎨 Как изменить персонажа - Подробная инструкция

## 📍 Где находится код персонажа

Файл: **`js/pixel-art.js`**

Это общий класс `PixelCharacter`, который рисует персонажа везде (на главной странице и в игре).

## 🖼️ Как работает рисование

### Система координат

```
Canvas:
┌─────────────────┐
│ (0,0)           │  ← Левый верхний угол
│                 │
│      👾         │  
│                 │
└─────────────────┘
```

Каждый "пиксель" персонажа = квадрат размером `size × size` (обычно 3x3px)

### Основная функция

```javascript
draw(ctx, x, y, animFrame, size = 3)
```

**Параметры:**
- `ctx` - контекст Canvas
- `x, y` - позиция персонажа на экране
- `animFrame` - номер кадра анимации (увеличивается каждый кадр)
- `size` - размер одного "пикселя" (3 на сайте, 2 в игре)

### Функция drawP() - рисует один пиксель

```javascript
const drawP = (px, py, color) => {
    ctx.fillStyle = color;
    ctx.fillRect(x + px * size, y + py * size, size, size);
};
```

**Пример:**
```javascript
drawP(10, 5, '#FF0000');  // Рисует красный квадрат на позиции (10, 5)
```

## 🎨 Структура персонажа (слои)

Персонаж рисуется **снизу вверх** по слоям:

### 1️⃣ **Волосы** (строки 0-5)
```javascript
// Голубой градиент из 4 цветов
for (let px = 7; px <= 17; px++) drawP(px, yPos + 1, c.hairLight);  // Светлый верх
for (let px = 6; px <= 18; px++) drawP(px, yPos + 2, c.hair);       // Основной цвет
for (let px = 5; px <= 19; px++) drawP(px, yPos + 3, c.hairDark);   // Темнее
for (let px = 4; px <= 20; px++) drawP(px, yPos + 4, c.hairShadow); // Тень
```

### 2️⃣ **Наушники** (строки 6-10)
```javascript
// Левый наушник
for (let py = 6; py <= 10; py++) {
    drawP(2, yPos + py, c.headphoneWhite);   // Белая часть
    drawP(3, yPos + py, c.headphoneGray);    // Серая часть
}
```

### 3️⃣ **Лицо** (строки 6-12)
```javascript
// Кожа с градиентом
for (let py = 6; py <= 12; py++) {
    for (let px = 5; px <= 18; px++) {
        // Разные оттенки кожи создают объем
        if (py === 6 || py === 12) {
            drawP(px, yPos + py, c.skinLight);  // Светлые края
        } else if (px === 5 || px === 18) {
            drawP(px, yPos + py, c.skinMid);    // Боковые тени
        } else {
            drawP(px, yPos + py, c.skin);       // Основной цвет
        }
    }
}
```

### 4️⃣ **Глаза** (строки 8-10)
```javascript
// Левый глаз - 3x3 пикселя
drawP(7, yPos + 8, c.eyeWhite);   // Белок сверху
drawP(8, yPos + 8, c.eyeWhite);   
drawP(9, yPos + 8, c.eyeWhite);
drawP(8, yPos + 9, c.eyeIris);    // Голубая радужка
drawP(8, yPos + 10, c.eyePupil);  // Черный зрачок
drawP(7, yPos + 8, c.eyeShine);   // Белый блик (реалистичность!)
```

### 5️⃣ **Анимация рук** (активная!)
```javascript
// Вычисляем позицию на основе времени
const armSwing = Math.floor(Math.sin(animFrame * 0.12) * 3);

// Левая рука - машет вверх
const leftArmY = 17 + armSwing;  // +3 вверх, -3 вниз

// Рисуем руку (10 пикселей длиной)
for (let py = 0; py <= 9; py++) {
    drawP(2, yPos + leftArmY + py, c.skin);
}
```

### 6️⃣ **Анимация ног** (дрыгаются!)
```javascript
// Вычисляем движение ноги
const legKick = Math.floor(Math.sin(animFrame * 0.15) * 2);

// Левая нога - двигается вперед (+2 пикселя)
const leftLegX = 7 + legKick;

// Рисуем ногу
for (let py = 36; py <= 42; py++) {
    drawP(leftLegX, yPos + py, c.pants);
    drawP(leftLegX + 1, yPos + py, c.pantsDark);  // Тень справа
}
```

## 🎯 Как изменить персонажа:

### 🎨 **Изменить цвета:**

Найдите в `js/pixel-art.js`:
```javascript
this.colors = {
    hair: '#4ECDC4',      // Измени на свой цвет волос!
    skin: '#FFE5D9',      // Цвет кожи
    pants: '#34495E',     // Цвет штанов
    // ...
}
```

### 📏 **Изменить размер частей тела:**

**Пример: Сделать руки длиннее**
```javascript
// Было:
for (let py = 0; py <= 9; py++) {  // Рука длиной 10 пикселей

// Стало:
for (let py = 0; py <= 14; py++) {  // Рука длиной 15 пикселей
```

### 🎭 **Изменить скорость анимации:**

```javascript
// Руки машут
const armSwing = Math.sin(animFrame * 0.12) * 3;
//                                    ^^^^   ^
//                                  скорость амплитуда

// Сделать быстрее: 0.12 → 0.20
// Сделать шире: 3 → 5
```

### ➕ **Добавить новую деталь (например, шапку):**

```javascript
// Добавь после волос:
// Шапка (красная)
for (let px = 6; px <= 17; px++) {
    drawP(px, yPos + 0, '#FF0000');  // Красный цвет
}
```

### 🎨 **Добавить новую анимацию:**

```javascript
// Пример: голова поворачивается влево-вправо
const headTurn = Math.floor(Math.sin(animFrame * 0.05) * 1);

// Рисуй глаза со смещением
drawP(7 + headTurn, yPos + 8, c.eyeWhite);  // Глаз двигается!
```

## 📊 Координаты персонажа (карта):

```
Строка   Что рисуется
───────────────────────
0-1      Черный контур (outline)
1-5      Волосы (cyan gradient)
6-10     Наушники (белые) + уши
6-12     Лицо (skin tones)
8-10     Глаза (детальные)
10-11    Нос
12       Рот
13-14    Шея
15-26    Тело (белая рубашка)
17-27    Руки (анимация!)
27-35    Штаны
36-42    Ноги (анимация!)
43-45    Обувь
```

## 🎮 Где применяются изменения:

Изменив `pixel-art.js`, персонаж обновится:
- ✅ На главной странице (большой)
- ✅ В игре (маленький)
- ✅ Все анимации сохранятся

## 📝 Шпаргалка по функциям:

```javascript
Math.sin(animFrame * скорость) * амплитуда
//       └─ счетчик кадров
//                   └─ как быстро (0.1 = медленно, 0.5 = быстро)
//                                └─ насколько сильно (1 = слабо, 5 = сильно)
```

Теперь можешь сам менять персонажа как хочешь! 🎨✨
